# Global Design Rules
- Typography: Use system monospace fonts or a rigid sans-serif stack. Do not import generic Google fonts like Inter or Roboto.
- Color Palette: Implement a strict monochrome theme with one primary accent color. Do not use standard Tailwind blue-to-purple gradients.
- Layout: Avoid centered text blocks and standard three-column symmetrical feature cards. Use asymmetrical grids, visible structural borders, and dense information layouts.
- UI Elements: Do not use rounded corners, soft drop shadows, or background blur effects. Enforce sharp edges and flat, solid borders.

# Code Constraints
- Do not add comments to the code.
